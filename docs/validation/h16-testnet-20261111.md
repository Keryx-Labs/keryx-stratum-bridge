## Limits

This run exercises the post-H16 rule set, which includes H15 PoM v5. It does not reproduce a separate historical H15-only crossing. It does not execute a paid private request, audit/attention cycle, reward recovery, mainnet deployment, remote TLS, sustained mixed workload or multi-worker pool load. Crypto response roundtrips and tampering refusals are local Rust tests, not on-chain inference acceptance.

No personal wallet or mainnet funds were spent. Test-only rewards were not claimed. Test processes were bounded, owned separately, and stopped after evidence collection; raw logs and secret state are excluded from this repository.
