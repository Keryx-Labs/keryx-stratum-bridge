## Defects exposed and corrected

Real diagnostic attempts exposed three bugs. Their regression tests failed against the preceding behavior, then passed after correction; the final table above comes from fresh requests on the corrected source, not from the failed attempts.

1. **Audit queries omitted response IDs.** `GetAwaitedOpenings` only enumerates response audits for explicitly supplied IDs. Queries now include every retained response ID, even after its request closes. `TestNodeObligationsQueryAuditsOfRetainedResponses` checks the RPC contract.
2. **Empty attention paths were encoded as both `null` and `[]`.** Canonical keys now use `[]`; retained phase-root keys and pending digests are migrated, and conflicting commitments stop recovery. `TestOpeningKeyMatchesRootAndChildParent` and `TestRetainedAttentionRootsMigrateWithoutDiscardingCommitments` cover the root/child lookup, migration and conflict refusal. A diagnostic attempt resumed a retained trace and completed the drawn child opening; that bounded observation is not general restart qualification.
3. **A transient readiness pause revoked miner authorization.** A ledger/template observation race could temporarily leave a draw without its retained canonical seed. Shares now receive retryable Busy (46) while the gate is closed; Unauthorized (24) still applies to unauthenticated workers. `TestTemporaryMiningReadinessDoesNotRevokeAuthorization` covers this distinction. Proof and readiness checks were not relaxed.

The final runtime source passed 39 Go test functions with race detection, zero failures and one skipped inherited manual third-party-pool snooper. Go vet and the Windows build passed. Eight Rust tests passed on the unchanged verifier. Earlier locked Cargo check/Clippy/release and Go vulnerability checks apply to unchanged verifier/dependencies; they are not represented as newly repeated scans after each Go-only correction.

## Limits and cleanup

This is bounded real mining, private inference, mining resumption and acceptance of the audits actually drawn for two short requests. It does not qualify every model, GPU, token budget, attention phase, historical mainnet transition, queue/load condition, general outage/reorg recovery, Linux/Docker, remote TLS deployment, mainnet reward or escrow recovery. No real sanction was induced; nonzero/stale strike behavior was checked by automated fixtures.

Preserve bridge state and owning miner traces. The node's escrow-key query cannot rediscover every response audit if its response ID has been lost. The bounded chain scan is not a substitute for this state or a complete historical-obligation inventory.

All owned test processes were stopped and closure receipts checked. Complete logs were checked after shutdown. Test process termination does not assert a graceful database shutdown. No personal wallet/mainnet funds were spent and no escrow claim was executed. Secrets, tokens, model data and raw runtime logs remain excluded from the repository.
